## 非目标覆盖声明
req.txt §3.2 原非目标「不复制全部请求」「只复制当前选中的那一条请求，绝不附带其他请求」经老板原话**明确覆盖**：
- 多选复制为新增能力（输出含清晰分隔、逐条保真、不混淆）。
- 单条复制仍是默认与主要场景，格式逐字符不变（冻结契约）。
- 其余非目标（不上传 / 不自动发 AI / 不美化 / 不改网络 / 不收集数据 / 不请求无关权限）继续有效。
